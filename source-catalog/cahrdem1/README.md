# cahrdem1

## Overview

This directory contains Canadian elevation data sourcing for the [Mapterhorn](https://github.com/mapterhorn/mapterhorn/) project. It provides access to high-resolution Digital Terrain Models (DTM) and related elevation datasets from Canada's official STAC catalog, this source is the 1m hrdem-mosaic collection (~7.7TB).

The **stac-crawl.py** helper utility makes it easy to discover and list specific data sources from multiple Canadian elevation collections (DTM, DSM, hillshade variants, etc.).  More information can be found in [stac-crawl.md](./stac-crawl.md)
