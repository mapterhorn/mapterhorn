FAQ

Can I use Mapterhorn tiles for commercial purposes?

Our goal is that you can use Mapterhorn tiles for commercial and non-commercial purposes. We aim to only include source datasets that are licensed similar to CC-BY or are less restrictive, i.e., we aim to exclude sources that have non-commercial or share-alike clauses. You can read the original data license PDFs under https://mapterhorn.com/attribution. They should be in sync with the released tiles.

Can I store Mapterhorn tiles offline or cache them?

Yes, offline storage and caching is in accordance with the source data licenses to the best of our knowledge.

What are the attribution requirements?

Many sources require attribution. You can link to https://mapterhorn.com/attribution for a full list of used sources. You can also host the attribution.json file yourself. To show an attribution specific to the locally used sources, have a look at the Attribute Visible Sources example.

Does Mapterhorn add its own license?

No, Mapterhorn does not add its own license to the aggregated dataset.

Do I have to attribute Mapterhorn?

No, but adding a Mapterhorn attribution to your maps and products may increase the visibility of the project and might help keep it alive in the future. So please add an attribution to Mapterhorn, but you are not required to do it.

Can I self-host the tiles?

Yes, you can download the PMTiles archives and self-host them.

Can I use the tiles.mapterhorn.com endpoint for commercial purposes?

Yes, you can use the tiles endpoint for commercial and non-commercial purposes in accordance with the original source data licenses.

Does the tiles.mapterhorn.com endpoint have rate-limiting?

Currently it does not have rate-limiting. For bulk downloads we recommend using the PMTiles archives together with for example the pmtiles extract cli tool.

I found a bug. How can I report it?

Please open a GitHub Issue describing what the bug is. Add a link like for example https://mapterhorn.com/viewer/#map=16.35/47.117079/9.08066 such that we know where it is.

I found a new dataset. How can I add it to Mapterhorn?

Please open a GitHub Issue for the new dataset. Ideally describe how the dataset can be downloaded and add a link to the source dataset license.
